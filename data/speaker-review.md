- 完整檢查全部 1,082 段字幕。
- 第一輪為 Whisper large-v3，第二輪以 large-v2 完整重辨。

- 這是語音辨識交叉檢查與文字校對，不是人工逐句聽辨，也不是政治事實查核。

## 檔案位置

- `data/`：可提交的網頁、字幕、逐字稿、角色與校對紀錄。
- `outputs/plpXPrOoV2w/media/`：本機影片與預覽圖片，不隨資料提交。
- `outputs/plpXPrOoV2w/work/`：原始轉錄、對齊、中間檔、第二輪辨識與瀏覽器截圖。
- `outputs/plpXPrOoV2w/work/original-export/`：校對前的顯示輸出備份。

## 重新輸出

```bash
uv run 2026-debate export --output-dir outputs/plpXPrOoV2w \
  --destination data --roles data/speaker-roles.json
```

此命令會讀取 `data/corrections.json`，不執行模型推論。來源文字或時間碼有變動時，校對檔案的指紋檢查會拒絕套用舊修訂。
